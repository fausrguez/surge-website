# Logos de puntos de venta

Logos descargados de las webs públicas de cada establecimiento para identificarlos en
`/donde-comprar`. Son marcas de sus propietarios y no implican patrocinio.

| Archivo | Establecimiento | Origen |
|---|---|---|
| `decathlon.svg` | Decathlon | Wikimedia Commons (`Decathlon - logo (France, 2024).svg`); decathlon.es bloquea la descarga directa |
| `cd-tamaraceite.webp` | CD Tamaraceite | https://cdtamaraceite.com/ |
| `gofit.svg` | GOfit | SVG inline de https://go-fit.es/centros/go-fit-las-palmas/ |
| `areafit.webp` | Areafit | https://www.areafit.es/ (versión blanca; se muestra sobre placa oscura) |
| `beats.webp` | Beats Fitness Club | https://beatsfitness.es/centros/beats-las-palmas/ |
| `macrofit.webp` | Macro Fit | Macrofit.es vía Wayback Machine (el dominio actual está en venta) |

Al cambiar de proveedor o de identidad visual, sustituir el archivo conservando el nombre.
